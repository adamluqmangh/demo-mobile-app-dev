# HOW TO RUN THE PROJECT FOR ANDROID
1. Open Project in VS Code or Android Studio
2. Select Android/Emulator & Run the emulator
3. run "flutter pub get" in compiler
4. run "flutter run"
5. Select which device to run
6. App is now running!

# HOW TO RUN THE PROJECT FOR IOS
1. Open Project in XCode (iOS/Runner.xcworkspace)
2. Select iOS Emulator & Run the emulator
3. run the app
4. App is now running!


# Software Versions

2. Dart - 3.9.2
3. iOS - 13.0
4. Android Studio - Android Studio Meerkat | 2024.3.1
5. XCode - Version 16.2 (16C5032a)
6. Android SDK - Corretto 1.8
7. Devices - Pixel 8 (API 36) & iPhone 16 (iOS 18.2)




# Extra Info 
1. Seat locking will release after 2 minutes
2. App runs on Firebase Realtime DB
3. Json File cinemaseats.json under the asset directory is the sample of seat structure in Firebase DB
4. google-services.json file is in android/app directory (for firebase android)
5. GoogleService-Info.plist file is in ios/Runner directory
